# Node-RED flow (v1)

Only a screenshot of the flow exists: [`flow_chart.jpg`](flow_chart.jpg).

If the flow is still installed, export it so it can be restored:

1. In Node-RED, select all nodes of the flow.
2. Open Menu → Export. Choose **Selected nodes** and **JSON**, then **Download**.
3. Save the file here as `flows.json`.

The export can contain Home Assistant server details. Check it for tokens
before you commit it.
